# Quaternius RPG Character Pack

This H2 prototype bundles optimized `Monk.glb` and `Warrior.glb` models from the free
[Quaternius RPG Character Pack](https://quaternius.com/packs/rpgcharacters.html).

- Creator: Quaternius (laulhet)
- Original release: November 2020
- License: CC0 1.0 Universal; see `LICENSE.txt`
- Use here: temporary Bio and sword-bandit prototype characters

The pack's glTF exports were optimized and converted to self-contained GLB files
with `@gltf-transform/cli`. Embedded textures use baseline PNG rather than a glTF
texture extension so the models load without an extra runtime decoder. Their
animations and CC0 status are unchanged. These are placeholder production assets,
not final Jarvis World character art.
